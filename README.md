VICE SUNSET SPLIT — a GTA 6-style cover art maker: diagonal-split multi-panel posters with white slanted gutters, 3 layouts (Diagonal Trio, Neon Quartet, Vice Five), 4 colour grades (Vice Sunset, Neon Night, Pastel Vice, Noir), and a big condensed Anton caption with a hard accent shadow and slanted accent bar. Each panel holds its own photo, cover-fit with drag-to-pan and zoom so faces stay framed, and one click exports a PNG in 1080×1080, 1080×1350 or 1920×1080. Fully offline — photos never leave the machine.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome.
